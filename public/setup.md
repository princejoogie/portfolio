# Prince Juguilon's Setup

## Systems

- **Arch Linux:** Main desktop environment, managed with pacman, yay, and GNU Stow.
- **Hyprland:** Wayland desktop with Waybar, Wofi, Eww, Dunst, and Hyprpaper.
- **macOS:** Portable environment with Homebrew, Raycast automation, and the same shell and agent setup.

## Terminal and editor

- **Neovim:** Lua configuration built on lazy.nvim, LSP, Treesitter, Snacks, Conform, Oil, Harpoon, and Fugitive.
- **Kitty:** Primary terminal with FiraCode Nerd Font and Catppuccin Mocha.
- **Zsh and Starship:** Vi mode, autosuggestions, syntax highlighting, and a compact language-aware prompt.
- **Tmux and Herdr:** Persistent sessions, worktree-aware panes, repository switching, and Neovim navigation.
- **Yazi:** Terminal file management alongside Oil and Snacks inside Neovim.

## AI and automation

- **OpenCode, Claude Code, and Codex:** Shared skills and MCP servers installed from one agent configuration.
- **Supermaven:** Inline completion inside Neovim, with Copilot intentionally disabled.
- **CuaDriver and MCP:** Computer-use automation with Context7, grep.app, and OpenTelemetry tooling available to agents.
- **Worktree scripts:** Create isolated branches, detect the package manager from lockfiles, install dependencies, and open the correct workspace.

## Desk

- LG 27-inch UltraGear OLED at 1440p and 240Hz
- Neo Ergo keyboard
- ZSA Moonlander split keyboard
- Scyrox mouse with HID battery status in Waybar
- Sony WH-1000XM5 headphones
- Edifier R1700BT bookshelf speakers

The complete configuration is available in [Prince's dotfiles](https://github.com/princejoogie/dotfiles).
