# Prince Juguilon Portfolio API

Base URL: `https://prince.juguilon.com/api/v1`

The API returns Prince Carlo Juguilon's public profile, structured resume, portfolio projects, and engineering article metadata. It uses JSON for success and error responses. Errors contain a stable `code`, a human-readable `message`, and a `resolution` hint. All operations are GET-only, anonymous, idempotent, read-only, and non-destructive.

Use [openapi.json](https://prince.juguilon.com/openapi.json) as the authoritative machine-readable contract and [developers.md](https://prince.juguilon.com/developers.md) for the integration guide.
